The signal — a coiled book = a chop day

At the open, sum the resting size on each side of the book (MBP-10, 09:30–09:40). A balanced / coiled book (low abs_imbal) means liquidity is stacked evenly both sides → price chops between it → both books get sawn off → stand down. A one-sided book says a real move is coming → trade. Threshold set on the train half only, then frozen.
