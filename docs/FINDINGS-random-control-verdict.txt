THE RANDOM-ENTRY CONTROL — the test this project owed itself (2026-09-08)

Declared as condition 6 of docs/PREREG-sma20-pinbar-reclaim.md: "Beats a matched RANDOM
entry (same session, same risk, same target) by > 0.10 R." The script was written on
2026-09-07 (commit d560d5c) and then never run; I twice told the trader we had never built
one. Both statements were wrong: it existed, unrun. It has now been run.

Method: for every real pin-bar signal, 20 matched random trades — same session day, same
NY window, same risk in points, same target multiple, same max hold, same cost. ONLY the
entry bar is randomised. Everything the geometry gives you is held constant, so what is
left is whatever the pin bar itself is worth.

================ RESULT ================
  tape/trend           rule       random (sd)        EDGE        sd above random
  2023-26 SIDE       +0.0711   +0.0932 (0.0712)    -0.0221          -0.31
  2023-26 SLOPE      +0.0646   +0.0588 (0.0459)    +0.0058          +0.13
  2020-22 SIDE       -0.0676   +0.0666 (0.0742)    -0.1342          -1.81
  2020-22 SLOPE      -0.0119   +0.0499 (0.0604)    -0.0619          -1.02
  2017-19 SIDE       -0.0258   +0.0776 (0.2094)    -0.1034          -0.49

Four of five negative. The best case is +0.0058 R at +0.13 sd, which is indistinguishable
from zero. Declared condition 6 required > +0.10 R. It FAILS on every surface.

================ WHAT THIS MEANS ================
The 20-SMA pin-bar entry rule carries NO INFORMATION. A coin flip that picks a random
minute inside the same session, with the same stop distance and the same 3R target, does
as well or BETTER. Every component the trader believed in — the wick crossing the SMA, the
close back through it, the 2x body wick, the bullish confirmation close, the trend gate —
is, in aggregate, worth less than nothing against the null.

This is consistent with everything else we measured and did not understand at the time:
  * the loser autopsy: no chart feature separated winners from losers by more than 10%
  * win rate tracked the break-even line 1/(1+RR) at every reward ratio
  * the only thing that ever moved the number was ORDER FLOW, not the candle

So the honest restatement: this was never a pin-bar strategy. The pin bar is a delivery
mechanism for what is effectively a random entry. IF anything here is real, it is the
order-flow filter (wick absorption + bar delta against the trade), and the pin bar is
decoration around it.

================ CONSEQUENCE FOR THE KILL SCREEN ================
Survivor 1 of docs/FINDINGS-kill-screen.txt — "SMA20 pin-bar reclaim 3R, 1-min SLOPE +
order flow", PF 1.329 — is KILLED. Its declared bar included the random control and it
fails it. Its base entry is worse than random on 4 of 5 surfaces; the entire apparent edge
came from the order-flow filter bolted on top, and that filter has NEVER been tested
against random entries.

THE NEXT TEST, AND IT IS THE ONLY ONE THAT MATTERS HERE
Run the random control on ORDER-FLOW-FILTERED random entries: pick random bars, compute
bar delta on them, keep the ones where delta ran against the trade direction, and compare.
Bar delta is well defined on any bar, so this is a fair comparison. If order-flow-filtered
random entries score like order-flow-filtered pin bars, then the pin bar is worthless AND
the order-flow filter is just selecting bars with a particular delta sign — and the whole
thing collapses. If the filtered pin bars still win, the filter and the pattern interact
and there is something to keep.

Until that is run, no number from the pin-bar family should be quoted.
