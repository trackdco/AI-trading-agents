Read this honestly. One book, 55 trades over 12.5 months, a single favourable regime — there is no 2023–24 London holdout, so out-of-sample behaviour is unproven. The 3.06R max equity drawdown is historical; the ~0.16% blow-probability is a Monte-Carlo estimate (8k–20k resampled paths incl. bootstrap-with-replacement) and is still an in-sample distribution — real forward streaks can be worse. Jan-2026 has no CVD (one missing file) so those trades size at the unconfirmed half-rung. Thresholds were frozen on 2025 and the book has been sliced many ways — treat any refinement as a holdout candidate, not a ship. Start at the bottom rung; the buffer is the protection.
