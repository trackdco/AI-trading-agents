NQ DESK · THE LONG WALK · FINAL RESULTS · FRESH-EYES 2023-2026 + CHAINED-VS-FRESH-EYES 2026

Memory helps — and now we know exactly what it helps with

Both arms of the overnight test are complete. Fresh-eyes: 912/912 requests answered, 884 gradeable days across all four years. Chained: 139/139, 127 gradeable days in 2026. Same books, same features, same health gate — the only difference is whether the agent remembers yesterday. Here's the full answer to both questions this test was built for: does performance improve year-on-year, and does memory help or hurt.

Chained +$14,465 (30%)  vs  Fresh-eyes +$10,913 (23%)
Identical 127 tradeable days in 2026, identical books, identical health gate. Chained wins by +$3,552 and 7 points of capture — and the mechanism is precise, not vague: flat-rate and risk_off calls are IDENTICAL between the two arms (17% / 17%, 0% health overrides each) — memory does not change when the desk stands down, because that's mechanically health-gated either way. The entire gap comes from book-choice accuracy — chained reads 39% vs fresh-eyes' 35%.

127 identical calendar days, same request files, same briefing JSON, same health signal. The only variable is whether the agent saw yesterday's carried notes before writing today's verdict.

What memory actually buys: better book calls, not better timing

Flat-rate is identical (17% both), and both arms asked for risk_off on the same 17% of days with zero cases where the health gate had to overrule an unjustified stand-down. That's expected — regime_health is a precomputed mechanical signal (trailing-20d champion P&L), the same number in both arms' briefings regardless of memory. Memory can't improve a decision that's already gated by a number both arms see identically.

The gap is entirely in book-choice accuracy: chained reads 39% of days correctly vs fresh-eyes' 35%, despite overriding the champion pick slightly less often (20% vs 22%) — chained isn't overriding more, it's overriding better. That's the carried playbook_notes doing real work: the 06-19→06-24 inventory-watch trace (published separately) shows the mechanism directly — a pattern flagged, tracked, and correctly weighted against fresher evidence days later.

3 · The honest caveat

This is one run of each, not multiple seeds. A 7-point capture gap on 127 days could partly be run-to-run agent variance rather than a guaranteed, repeatable memory effect. What makes it more believable than pure noise: the flat-rate/health-gate numbers match exactly between the two arms (17.32% precisely — not just "close"), which is what you'd expect if the only real difference is book-choice reasoning and nothing else changed procedurally. If this were just noise, matching that precisely on an independent mechanical signal would be a coincidence. Worth another chained run on a different year (2024 or 2025) before fully banking "memory adds ~7 points of capture" as a number to design around — but as a first, clean answer to "does memory help or hurt": it helps, and it helps specifically with book selection.
